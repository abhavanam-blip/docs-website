New Relic offers an [integration](/docs/infrastructure/introduction-infra-monitoring) that fetches data about your [Google API Gateway](https://cloud.google.com/api-gateway/) services so that you can view the data in the New Relic UI.

## Features of the Google API Gateway integration [#features]

You can use the Google API Gateway integration to view charts and set <InlinePopover type="alerts"/> for your Google API Gateway services in New Relic and to [create custom queries and charts](/docs/using-new-relic/data/understand-data/query-new-relic-data). Google API Gateway is a fully managed gateway that enables you to secure, monitor, and manage your APIs running on Google Cloud.

## Activate integration [#activate]

To enable the integration follow standard procedures to [connect your GCP service to New Relic](/docs/connect-google-cloud-platform-services-infrastructure).

## Polling frequency [#polling]

New Relic queries your Google API Gateway services based on a polling interval of 5 minutes. The resolution is 1 data point every minute.

## Metric data [#metrics]

To view [metric data](/docs/telemetry-data-platform/understand-data/new-relic-data-types/#metrics) for your Google API Gateway integration in New Relic, [create NRQL queries](/docs/integrations/new-relic-integrations/getting-started/use-integration-data-new-relic-insights#nrql) for `GcpApiGatewaySample` [events](/docs/data-apis/understand-data/new-relic-data-types/#event-data) and their related attributes.
